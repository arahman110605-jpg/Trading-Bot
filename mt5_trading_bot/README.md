# MetaTrader 5 (MT5) Trading Bot

Automated trading bot tailored for MetaTrader 5 (Forex, Indices, Commodities, Crypto).

## Directory Structure
- `broker/`: MT5 API connector and order management wrapper.
- `strategies/`: Trading strategies and signal generation logic.
- `engine/`: Execution engine and risk management.
- `utils/`: Helper utilities, logging, and notifications.
- `config.py`: Bot configuration settings and environment variable loading.
- `main.py`: Main entry point to run the MT5 bot.
- `requirements.txt`: Python package dependencies (e.g. `MetaTrader5`, `pandas`, etc.).
- `.env.example`: Template for credentials and broker settings.
